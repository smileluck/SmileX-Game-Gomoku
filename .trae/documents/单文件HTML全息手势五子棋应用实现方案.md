# 单文件HTML全息手势五子棋应用实现方案

## 1. 项目概述

本项目将开发一个基于手势交互的3D全息五子棋应用，支持实时手势控制、视觉特效与AI对战。应用将以单文件HTML形式实现，便于部署和使用。

## 2. 技术架构

### 2.1 核心技术栈
- **Three.js**：用于构建3D全息棋盘、发光棋子和粒子特效
- **MediaPipe Hands**：实时手部骨骼追踪，支持左右手区分
- **UnrealBloomPass**：实现强辉光后处理，营造霓虹科技感
- **Canvas 2D**：叠加层绘制手部骨骼连线

### 2.2 项目结构
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>全息手势五子棋</title>
    <style>/* CSS样式 */</style>
</head>
<body>
    <canvas id="three-canvas"></canvas> <!-- Three.js 3D场景 -->
    <canvas id="hand-canvas"></canvas> <!-- 手部骨骼绘制 -->
    <script>/* 完整JavaScript代码 */</script>
</body>
</html>
```

## 3. 核心功能模块设计

### 3.1 3D场景搭建

#### 3.1.1 场景初始化
- 创建Three.js场景、相机和渲染器
- 配置OrbitControls（可选，用于调试）
- 设置深空径向渐变背景

#### 3.1.2 棋盘设计
- 构建15x15网格棋盘（标准五子棋尺寸）
- 使用发光材质创建悬浮网格线
- 添加棋盘边框发光效果

#### 3.1.3 棋子设计
- 玩家棋子：青色(Cyan)发光材质
- AI棋子：红色(Red)发光材质
- 棋子悬浮效果：轻微上下浮动动画

### 3.2 手势追踪系统

#### 3.2.1 MediaPipe Hands集成
- 初始化MediaPipe Hands模型
- 配置摄像头参数
- 实时处理视频流，获取手部骨骼数据

#### 3.2.2 手势映射逻辑
- 提取食指指尖坐标
- 将2D屏幕坐标映射到3D棋盘空间
- 实现光标跟随效果

#### 3.2.3 磁吸锁定与落子
- 计算拇指与食指距离
- 距离＜5%时，光标吸附到最近网格点
- 捏合动作触发落子（防抖动处理）

### 3.3 视觉特效系统

#### 3.3.1 辉光效果
- 配置UnrealBloomPass后处理
- 调整辉光强度、半径等参数
- 实现棋盘和棋子的霓虹发光效果

#### 3.3.2 手部骨骼绘制
- 在Canvas层实时绘制手部骨骼连线
- 与3D场景对齐，实现视觉融合
- 使用青色科技风线条样式

### 3.4 特效反馈系统

#### 3.4.1 玩家落子特效
- 生成全息震波(Shockwave)效果
- 震波由中心向外扩散，逐渐衰减
- 伴随粒子爆发效果

#### 3.4.2 AI落子特效
- AI思考后，生成红色轨道激光(Orbital Laser)
- 激光从“天空”射向目标位置
- 激光消失后生成AI棋子

### 3.5 五子棋逻辑

#### 3.5.1 棋盘状态管理
- 维护15x15棋盘数组
- 实现落子位置合法性检查
- 记录落子历史

#### 3.5.2 AI对战算法
- 实现极大极小值算法（Minimax）
- 添加Alpha-Beta剪枝优化
- 支持3-5层搜索深度

#### 3.5.3 胜负判定
- 检查横向、纵向、对角线四个方向
- 连续5子获胜判定
- 游戏结束时的视觉反馈

## 4. 实现要点与优化

### 4.1 性能优化
- 限制Three.js渲染帧率
- 优化粒子系统，避免过多粒子
- MediaPipe Hands模型选择轻量版本

### 4.2 用户体验
- 添加游戏状态提示（如当前回合、胜负结果）
- 实现游戏重置功能
- 添加音效反馈（可选）

### 4.3 兼容性
- 确保在现代浏览器中正常运行
- 处理摄像头访问权限问题
- 适配不同屏幕尺寸

## 5. 预期效果

1. **视觉效果**：具有强烈科技感的全息3D场景，棋盘和棋子发光，背景为深空渐变
2. **交互体验**：流畅的手势控制，精准的落子操作，丰富的特效反馈
3. **AI对战**：具有一定智能的AI对手，适合休闲对战
4. **响应速度**：实时的手势追踪和渲染，无明显延迟

## 6. 部署与使用

- 直接在浏览器中打开HTML文件
- 允许摄像头访问权限
- 使用食指控制光标，拇指与食指捏合落子
- 与AI进行五子棋对战
