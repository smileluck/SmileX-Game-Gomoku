# 全息手势五子棋

一个基于Three.js和MediaPipe Hands的全息手势控制五子棋游戏。

## 功能特点

- 🎮 **手势控制**：使用MediaPipe Hands实现实时手势追踪，通过食指控制光标，捏合手势落子
- 🔮 **全息效果**：基于Three.js的3D场景，带有辉光效果和动态视觉反馈
- 🧠 **AI对战**：内置AI对手，使用极小极大值算法（带Alpha-Beta剪枝）
- 🎯 **流畅体验**：平滑的动画效果和响应式交互
- 📱 **跨平台**：支持浏览器直接运行，无需安装
- 📖 **可折叠操作说明**：详细的操作指南，可折叠收起

## 技术栈

- **Three.js**：3D场景渲染和动画
- **MediaPipe Hands**：实时手势追踪
- **HTML5 Canvas**：2D手部骨骼绘制
- **JavaScript (ES6+)**：核心游戏逻辑
- **CSS3**：样式设计和动画效果

## 快速开始

### 本地运行

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/SmileX-Project/SmileX-Game-Gomoku.git
   cd SmileX-Game-Gomoku
   ```

2. **启动本地服务器**
   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 或使用Node.js http-server
   npx http-server -p 8000
   ```

3. **在浏览器中打开**
   ```
   http://localhost:8000
   ```

### 直接运行

也可以直接在浏览器中打开 `index.html` 文件，但某些浏览器可能会限制摄像头访问。建议使用本地服务器运行。

## 游戏规则

1. **基本规则**：先连成五子一线（横、竖、斜）者获胜
2. **落子顺序**：玩家执青色棋子先行，AI执红色棋子后行
3. **胜负判定**：任意方向连成五个同色棋子即获胜
4. **平局**：棋盘填满仍未分出胜负则为平局

## 操作指南

### 手势操作

1. **控制光标**：使用食指指向棋盘区域
2. **锁定位置**：拇指和食指靠近（捏合）
3. **完成落子**：保持捏合状态，系统自动识别落子
4. **手部识别**：系统会实时绘制手部骨骼，确保手势被正确识别

### 鼠标操作（备选）

1. **移动光标**：鼠标在棋盘区域移动
2. **锁定位置**：按住鼠标左键
3. **完成落子**：松开鼠标左键

### 重置游戏

点击右上角的"重置游戏"按钮重新开始游戏。

## 核心功能实现

### 1. 3D场景渲染

- 使用Three.js创建3D棋盘和棋子
- 实现辉光效果和动态光照
- 添加平滑的相机控制

### 2. 手势追踪

- 集成MediaPipe Hands进行实时手势识别
- 将手部坐标映射到3D场景中
- 实现手势状态检测（捏合、指向等）

### 3. AI对战

- 基于极大极小值算法实现AI决策
- 采用Alpha-Beta剪枝优化搜索效率
- 评估函数考虑连子模式和位置优先级

### 4. 视觉效果

- 玩家落子的全息震波效果
- AI落子的激光轨道效果
- 平滑的过渡动画
- 响应式UI设计
